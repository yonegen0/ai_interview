# AI面接練習Webアプリ｜プロジェクト計画書

> 文書バージョン: 2.1\
> 更新日: 2026-09-11  
> 対象フェーズ: Backend実装・Terraform構築・実API接続  
> 情報源方針: 実装時は最新の公式ドキュメントを最優先で再確認する。


## 1. 目的
転職者がスマートフォンから隙間時間に一問ずつ面接練習でき、
入力した回答に対してAIが短時間で構造化フィードバックを返すMVPを構築する。

## 2. 最優先ユーザーフロー
練習開始 → カテゴリ選択 → 質問 → 回答 → AI評価 → フィードバック → 再挑戦/次の質問。

## 3. 現在地
Frontend主要フローとMSW Mockは実装済み。E2Eには既知のWebP寸法不一致が残る。
認証・実AI・Backend・AWS公開・履歴・PWAは未実装。
今後はBackend、AWS Infrastructure、実API接続を中心に進める。

## 4. 採用技術
- Frontend: Next.js / React / TypeScript / MUI / Storybook / MSW / Vitest / Playwright（PWAは将来機能）
- Backend: AWS Lambda / Python
- Auth: Amazon Cognito User Pool
- API: API Gateway HTTP API
- DB: DynamoDB On-Demand
- AI: OpenAI Responses API
- IaC: Terraform
- Hosting: Private S3 + CloudFront OAC

## 5. 開発順序
1. Backend要件定義
2. 採用済みFrontend契約の確認と追加Route要件
3. DynamoDB Access Pattern
4. Lambda責務・非同期起動と受付整合・障害回復設計
5. OpenAI Prompt / Structured Output
6. Error / Retry / Idempotency
7. IAM
8. Terraform
9. Monitoring / Logging
10. Test
11. Backend実装
12. Infrastructure構築
13. Frontend実API接続
14. Integration / E2E
15. Model Evaluation

## 6. 判断基準
MVP中心フロー品質 > セキュリティ > シンプルさ > 保守性 > コスト > 将来変更容易性。

## 7. MVP非採用
Bedrock / RDS / ECS / EKS / SQS / Step Functions / NAT Gateway / ALB /
REST API / WebSocket / RAG / Vector DB / OpenAI Tools / 高度分析Dashboard。
