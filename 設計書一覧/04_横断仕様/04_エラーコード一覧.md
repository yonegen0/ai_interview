# エラーコード一覧

> 文書バージョン: 2.1\
> 更新日: 2026-09-11  
> 対象フェーズ: Backend実装・Terraform構築・実API接続  
> 情報源方針: 実装時は最新の公式ドキュメントを最優先で再確認する。

[HTTP・復旧動作の正本](../../docs/FRONTEND_API_CONTRACT.md)と[実装の写像](../../frontend/src/lib/api/client.ts)を参照。

| Code | HTTP | 用途 |
|---|---:|---|
| VALIDATION_ERROR | 400 | 入力不正 |
| UNAUTHORIZED | 401 | Token不正・不足 |
| FORBIDDEN | 403 | 権限不足 |
| SESSION_NOT_FOUND | 404 | Sessionが存在しない |
| ATTEMPT_NOT_FOUND | 404 | Attemptまたは対応Evaluationが存在しない |
| SESSION_STATE_CONFLICT | 409 | 現在の質問・Attemptと操作が競合 |
| IDEMPOTENCY_CONFLICT | 409 | 同一キーでMethod・Path・Payloadが不一致 |
| EVALUATION_NOT_COMPLETED | 409 | 未完了のFeedback取得 |
| RATE_LIMITED | 429 | 利用制限 |
| INTERNAL_SERVER_ERROR | 500 | 想定外 |
| AI_UPSTREAM_ERROR | 502 | HTTPリクエストとして評価サービス側の異常を通知 |
| AI_TIMEOUT | 504 | HTTPリクエストとして評価サービスのTimeoutを通知 |

Error Bodyは{ code, message }。Frontendは既知codeを日本語へ写像し、未知codeは汎用表示にする。
Backendのmessageは直接表示しない。汎用NOT_FOUNDやINTERNAL_ERRORへの置換は行わない。

## 評価状態と通信エラー

評価自体の失敗はHTTP 200の評価GETでstatus=failedとerror（例: EVALUATION_FAILED）を返す。
現在の評価失敗画面へ進み、error.messageは直接表示しない。
HTTP 502/504だけで評価自体の失敗を確定しない。受付不明のPOSTは同じキーとPayloadで手動確認する。
HTTP 403/429を自動再送しない。その他のRetry・未確定判定は現API Clientの動作を維持する。

## 追加する表示

| Code | 日本語表示 |
|---|---|
| FORBIDDEN | この操作を行う権限がありません。 |
| RATE_LIMITED | 利用が制限されています。時間をおいて再度お試しください。 |
| AI_TIMEOUT | 評価処理に時間がかかっています。結果を再確認してください。 |
| AI_UPSTREAM_ERROR | 評価サービスで問題が発生しました。 |

Client内のNETWORK_ERROR／TIMEOUT／ABORTED／INVALID_RESPONSEと既存表示も維持する。
