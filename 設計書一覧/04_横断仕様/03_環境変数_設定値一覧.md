# 環境変数・設定値一覧

> 文書バージョン: 2.0  
> 更新日: 2026-09-11  
> 対象フェーズ: Backend実装・Terraform構築・実API接続  
> 情報源方針: 実装時は最新の公式ドキュメントを最優先で再確認する。


## Backend候補
```text
APP_ENV
AWS_REGION
DYNAMODB_TABLE_NAME
QUESTION_BANK_SOURCE
LLM_PROVIDER=openai
LLM_MODEL=<model-id>
LLM_REASONING_EFFORT=low
PROMPT_VERSION=<version>
OPENAI_AUTH_MODE=wif|secret
OPENAI_SECRET_ID=<secret-id>   # secret方式のみ
```

Secret値そのものは環境変数へ設定しない。

## Frontend候補
公開可能なAPI Base URL / Cognito Client設定のみ。
秘密情報は置かない。
