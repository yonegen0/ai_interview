# AIモデル評価設計

> 文書バージョン: 2.1\
> 更新日: 2026-09-11  
> 対象フェーズ: Backend実装・Terraform構築・実API接続  
> 情報源方針: 実装時は最新の公式ドキュメントを最優先で再確認する。


## 1. 比較候補
- GPT-5.6 Luna / low
- GPT-5.6 Luna / medium
- GPT-5.6 Terra / low

## 2. Dataset
実利用を模した50〜100件程度の回答を用意。
Categoryを偏らせない。

## 3. 評価指標
- score（0〜100整数）の妥当性
- summaryの適切さ
- strengthsの具体性
- improvementsの有用性
- exampleAnswerの自然さ（省略時は省略の妥当性）
- 事実追加率
- 誇張率
- JSON/Schema成功率
- latency
- input/output token
- cost

## 4. 採用判断
品質差が小さい場合は低コスト・低Latency側を優先。
Prompt Version / Model Versionを結果に保存する。

評価データ形式は[AI評価詳細](../03_詳細設計/Backend/04_AI評価_OpenAI詳細設計.md)に合わせる。
モデル名は設計時の候補であり、APIモデルID・利用可否・SDK互換性は実験前に公式確認する。
