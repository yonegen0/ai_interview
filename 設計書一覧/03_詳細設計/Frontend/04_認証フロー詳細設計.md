# Frontend認証フロー詳細設計

> 文書バージョン: 2.1\
> 更新日: 2026-09-11  
> 対象フェーズ: Backend実装・Terraform構築・実API接続  
> 情報源方針: 実装時は最新の公式ドキュメントを最優先で再確認する。


現在は認証なしのMSW単体MVP。以下は次工程の設計であり、ログイン画面・SDK・トークン保存の仮実装は今回追加しない。

## 1. Login
Email入力 → Email OTP要求 → OTP入力 → Cognito Login → Access Token取得。

## 2. Credential
名前はLogin Credentialにしない。
名前はProfile情報。

## 3. Token
APIにはAccess Tokenを使用。
API Gateway JWT Authorizerで検証する。

## 4. Route Control
FrontendのRoute GuardはUX用。
最終的な認可判断はBackendで行う。

## 5. 実API接続前の完了条件

Access Token付与・更新、認証切れ時の導線を定義し実装する。
ログアウト・ユーザー切替時のQuery Cacheと下書き・未確定要求の分離／破棄を決定する。
現sessionStorageの保存形式を今回変更せず、本人以外のデータが表示されないことを認証接続時に検証する。
