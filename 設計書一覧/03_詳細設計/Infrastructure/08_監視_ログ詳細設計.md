# 監視・ログ詳細設計

> 文書バージョン: 2.1\
> 更新日: 2026-09-11  
> 対象フェーズ: Backend実装・Terraform構築・実API接続  
> 情報源方針: 実装時は最新の公式ドキュメントを最優先で再確認する。


## 1. Log可能
requestId, evaluationId, userIdHash, provider, model,
reasoningEffort, promptVersion, inputTokens, outputTokens,
latencyMs, status, errorType。

## 2. Log禁止
氏名、メール、電話、回答全文、質問全文、Prompt全文、
改善回答全文、OpenAI Credential、Access/Refresh Token。

## 3. Metrics
Lambda Errors / Duration / Throttles、
API 4xx / 5xx、
OpenAI Error / Timeout、
Evaluation Failure Rate、
p50 / p95 / p99 latency。

## 4. Alarm
閾値は実測後に調整。

## 5. 非同期評価の運用設計

受付後の起動漏れ・processing滞留・失敗・重複処理を検出する方法をBackend着手前に決定する。
requestId／evaluationId／userIdHashで関連付け、回答・質問本文はログに追加しない。
アラーム・回復手順・検証Scenarioを[必須事項](../../04_横断仕様/06_決定事項_未確定事項.md)として設計する。
