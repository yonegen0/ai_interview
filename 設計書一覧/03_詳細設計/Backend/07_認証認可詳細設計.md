# Backend認証認可詳細設計

> 文書バージョン: 2.0  
> 更新日: 2026-09-11  
> 対象フェーズ: Backend実装・Terraform構築・実API接続  
> 情報源方針: 実装時は最新の公式ドキュメントを最優先で再確認する。


## 1. Authentication
API Gateway HTTP API JWT Authorizer。

## 2. USER
対象UserはJWT `sub`から確定。
Request body/queryから任意userIdを受け取っても主体判断には使用しない。

## 3. ADMIN
`admin-api`で`cognito:groups`に`ADMIN`があることを再検証。
不足時403。

## 4. Principle
Frontend Route GuardはSecurity Boundaryとしない。
最終認可はBackend。
